# 第E08期 · 游戏与IP文娱——复制成本为零的内容

> 《钱在哪里》全景计划 · 行业篇 实榜第8 ｜ 2026-10-31 ｜ 数据时点：2025年报+2026年半年报
> 行业篇收官期。本期结论：**游戏是内容行业里唯一跑通「复制成本为零」的形态（影视音乐的反例组），出海是唯一按美元结算的文化输出（204.55亿美元真金白银 vs 创新药1357亿理论值）；从业者的钱极度右偏——95%独立游戏亏损与人均73万并存。**

---

## 核心发现（30秒版）

1. **三重结构性优势**：游戏赚钱而影视音乐普遍亏损（华谊连亏8年累计超81亿），差异在——F2P内购变现深度不设上限、服务器服务化是最强反盗版、长线运营摊薄边际成本。
2. **出海第二曲线是真金白银**：2025年自研游戏海外收入204.55亿美元(+10.23%)；《无尽冬日》21亿美元连续24个月出海冠军；对照创新药License-out的1357亿美元「理论总额」——游戏出海几乎全是玩家直接付费。
3. **《黑神话：悟空》验证了单机天花板与IP外溢**：约2800万份/约90亿元（第三方口径）+山西文旅单项目增收1.66亿元——「一次创作→多轮变现」的中国样本。
4. **从业者的钱极度右偏**：上市游戏公司人均约30万（昆仑73万/吉比特71.39万拉高），应届白菜30-40万、策划65-70万封顶、程序/TA头部80-150万；**Steam约95%独立游戏亏损、40%新品收入不足100美元**。
5. **版号从生存风险降级为节奏风险**：2025年全年1771款（+20%、七年新高）、每月常态化发放；裁员从2023全面型转为2024-2026项目型——「行业没了」的担忧让位于「项目组没了」。

---

## 一、IP经济学：一次创作如何变成永续现金流

- **盘子**：2025年中国游戏IP市场预计2753.9亿元，原创游戏IP占49.2%——从「改编外来IP」走向「原创反哺全产业链」。
- **两条「中国迪士尼」半程路径**：泡泡玛特（371.2亿/+184.7%、17个IP破亿、LABUBU破百亿）走「IP形象→潮玩零售→乐园授权」；米哈游（2025年总收入约780亿，媒体口径）走「游戏内容→多平台发行→衍生投资」。
- **长青游戏的续费成本**：腾讯14款长青游戏（QAU 200万/500万+年收入40亿+）构成2416亿游戏收入的稳定底盘；王者荣耀DAU 1.39亿运营十年——但内容更新成本无公司单列（「高成本续费」只能间接推断）。
- **授权金行情**：腰部IP保底10-50万/年+分成5-8%；头部量级无公开成交记录——暴雪对华授权年收入不到20亿元是唯一可核的上限锚；2026年品牌方授权预算普遍下降。
- **最大缺口**：影视→乐园→消费品的跨媒介闭环没有本土复刻者——上海迪士尼仍靠这个闭环拿最大品牌效应；反方观点：游戏原生IP已用数字分发替代乐园，「中国不需要迪士尼」。

## 二、出海：按美元结算的文化输出

| 指标 | 数字 | 说明 |
|---|---|---|
| 2025年自研游戏海外收入 | **204.55亿美元(+10.23%)** | 人民日报引官方报告 |
| 《无尽冬日》 | 21亿美元(+45%) | 连续24个月出海手游冠军 |
| TOP30发行商 | 约233亿美元 | Sensor Tower口径 |
| 《黑神话：悟空》 | 约2800万份/约90亿元（第三方口径） | 首日450万份/15亿元；山西文旅增收1.66亿 |
| 买量成本 | 全球CPI +30%；国内TOP100 +86.6% | 买量型出海边际成本陡升 |

- **渠道博弈**：30%苹果税的绕开路径——苹果小型企业/小程序计划降至15%（有条件）、网页直充（米哈游系标配）、Epic 12%；**绕开30%本身就是一门运营学问**。
- **市场结构**：美日韩前三；沙特11.9亿美元高增低基数（主权基金叙事，不宜高估）。
- **与E05对照**：游戏出海204.55亿美元≈全是现金；创新药出海1357亿美元≈理论总额——**同样是出海，成色天差地别**。

## 三、从业者的钱：人均是幻觉，项目是单位

| 层级 | 数字（年总包） | 口径 |
|---|---|---|
| 上市公司人均 | 约30万（昆仑万维近73万、吉比特71.39万） | 高管+少数高岗拉高；19/32家减员 |
| 应届白菜 | 约30-40万 | 腾讯校招口径 |
| 策划3-5年 | 30-40万常见、65-70万封顶 | 猎头体感 |
| 米哈游月薪分布 | 37-47K占37%、47-56K占31% | 职友集自报 |
| 头部程序/TA | 总包80-150万 | 猎头与社区报价 |
| 美术缺口 | 高水平月薪5-6万 | 当期结构性高薪 |

- **裁员换了性质**：2023年全面型→2024-2026项目型整组解散；完美世界减员超3成——但大盘+14.08%在增长，**裁员是效率化与品类集中，不是需求萎缩**。
- **独立开发者的真实分布**：Steam约95%独立游戏亏损；2025年40%新品收入不足100美元（连上架费都没赚回）；底层30%均值37美元、顶部5%超30万美元——**创作变现是彩票型收入，期望值必须用全分布计算**。
- **小游戏是低门槛端的另一面**：约400亿盘子对应微信40万开发者（IAP月活3亿/IAA月活4亿）——小额但正的现金流是常态，暴富是例外。

## 四、反面：监管的钟摆与社会成本之争

- **防沉迷实效（自证口径）**：未成年每周>3小时占比24.9%（较2021年降37.2pct）；≤3小时占71%连续四年稳定；约九成无消费——但数据出自游戏工委问卷，监管边界已到「家庭攻坚」。
- **版号经济学（观点级争论，无因果识别）**：正方——配额倒逼精品化；反方——停发期（2021.8-2022.4）断崖与中小厂商出清；事实：2025年1771款常态化放量后，政策风险已降级。
- **成瘾之争**：WHO ICD-11三要件+12个月门槛 vs 舆论「游戏成瘾」泛化——医学共识远未完成（DSM-5仅列附录）。
- **贡献口径之争**：流水3000亿≠GDP增加值；就业税收散落无全行业口径；「电子海洛因」（2000）到「政协提案税收优惠」（2026）——**社会成本与经济贡献的权重随监管周期摆动，双方都未被证伪**。

## 五、与你的坐标

- **游戏业的峰位岗位**：程序/TA（80-150万）> 策划 > 基础美术；当前结构性缺口是高水平美术（5-6万/月）。
- **与地学/技术背景的接口**：技术美术（TA）、引擎开发对数理背景开放；出海本地化运营是小语种+游戏的复合位。
- **独立开发的期望值**：把「95%亏损、40%<100美元」当基准率——副业创作按彩票定价，主业按项目风险定价。
- **对照E02**：游戏是平台生态里分成结构最好的内容形态（研发型公司利润近8成分红，如吉比特）；内容创作者的终极形态=做出自己的「长青游戏」。

## 六、本期结论（行业篇收官）

游戏与IP是「**复制成本为零的生意里唯一被中国公司全面跑通的形态**」：出海按美元结算、长青游戏按十年计提现金流、IP按「一次创作多轮变现」复利；但从业者的钱极度右偏、独立创作是彩票、版号钟摆随时可能回摆。**行业篇八期（E00-E07）合起来的答案：钱的密度由「垄断性×变现深度×政策射程」三者相乘决定——金融赢在牌照、平台赢在网络效应、游戏赢在服务化反盗版、资源赢在租金、医药赢在专利、白酒赢在品牌——而所有行业的打工人份额，都由「可替代性」单独定价。**
