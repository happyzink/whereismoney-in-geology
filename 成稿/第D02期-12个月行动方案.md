# 第D02期 · 12个月行动方案

> 《钱在哪里》全景计划 · 定位篇 D02 ｜ 2026-11-02 ｜ 覆盖窗口：2026-11 ～ 2027-10
> 全部 20 期研究的落地文件。**第一原则（写死）：毕业优先——2026 年 11-12 月的答辩、试讲、论文终稿永远排在第一档，本方案的任何动作与之冲突时自动让路。**

---

## 0. 方案的骨架：一个公式、四层资产、三条防线

**个人总包 = 主业（窗口岗或峰位岗）+ 副业（专家网络/知识付费）+ 资产（三档模板）− 杠杆风险**

- 四层资产：人力资本（峰位/窗口岗）> 现金流（副业）> 投资组合（定投+再平衡）> 不碰的东西（刚兑幻觉产品、赌性期权、投资性房产）
- 三条防线：①负债率≤50%、月供收入比≤30-40%（M02）②offer股权按0.4-0.6折算、不为股权降薪（P02）③一切以协议文本为准、拒绝口头承诺（P02判决书纪律）

## 1. Q1（2026-11 ～ 2027-01）：毕业冲刺期——主业是学位

**最高优先级（不可谈判）**：
- [ ] 答辩 PPT 成稿 + 试讲≥2 次（目标 11 月上半月 PPT 定稿）
- [ ] 学位论文终稿与外审收尾；与导师敲定答辩申请与时间
- [ ] 12 月毕业目标不变

**并行轻动作（每周≤3小时，不让路但也不喧宾夺主）**：
- [ ] 注册专家网络（凯盛/GLG），完善专家档案（矿业/新能源金属/碳中和方向）——目标：12 月底前接首单（P03：时薪约1,300元/小时）
- [ ] 建立求职弹药库：把 P01 峰位选择树、D01 八去向表转成投递清单（矿业海外定岗 10 家 + 量化/领域AI 15 家 + 选调/军队文职报名日历）
- [ ] 财务基线：记一个月支出账，算出「过渡期月成本」（为断层期预留现金做依据，M02 安全边界）

**Q1 可验证里程碑**：✅ 答辩通过（12月毕业目标）｜✅ 专家网络首单入账｜✅ 投递清单≥25个岗位

## 2. Q2（2027-02 ～ 2027-04）：求职主攻期——两条腿走路

**留的最优解（主攻）**：
- [ ] 矿业海外定岗申请：紫金/洛钼/中资矿企国际部（D01：溢价2-4倍，≥36万 vs 国内8-18万；窗口2026-2028）
- [ ] 地调系统/选调/军队文职报名（体制内四档对照，注意地质队待遇需内部人核实）

**换的探路（并行）**：
- [ ] 量化/领域AI（地学大数据）实习或校招投递——按 P01 选择树，用 offer 结果而非情绪做决策
- [ ] 每个面试用 P02 五问清单反向尽调公司（清算优先权/归属条款/回购条款）

**资产与副业**：
- [ ] 专家网络保持每月 1-2 单（时间审计：不挤占面试准备）
- [ ] 开启定投（P04 保守→平衡档，金额=不影响断层期现金储备的小额起步）

**Q2 可验证里程碑**：✅ 投递≥40个、面试≥8场｜✅ 拿到≥1个窗口岗或峰位岗offer｜✅ 定投连续3个月

## 3. Q3（2027-05 ～ 2027-07）：决策期——用 D01 条件化纪律做终局选择

**决策闸门（本方案的灵魂）**：
- [ ] **有实习转正/峰位offer确定性 → 换赛道**（接受6-18个月断层成本，因为它已被offer对冲）
- [ ] **无确定性 → 留编/矿业窗口岗+专家网络副业**（中位350-540万/10年，确定性溢价）
- [ ] 决策用 D01 期望值表逐档核对，写一页决策备忘录（避免情绪漂移）

**技能启动**：
- [ ] 注册岩土工程师备考启动（硬门槛证书，D01窗口技能）
- [ ] 三维建模（GoCAD/Surpac）练手——智能矿山入场券

**Q3 可验证里程碑**：✅ 签约（任一路径）｜✅ 决策备忘录成文｜✅ 备考计划启动

## 4. Q4（2027-08 ～ 2027-10）：落地与资产期

- [ ] 入职过渡：第一个月搞清薪酬结构真实口径（对照 P01 口径五陷阱）
- [ ] 副业常规化：专家网络每月固定节奏（年化13-20万目标）；视精力启动专业垂类内容（知乎/公众号，按 M04 阶梯）
- [ ] 资产上量：定投升级至平衡档（宽基40%±+黄金10-15%+债30%）；建立再平衡日历（每半年或±5-10pp）
- [ ] 红线自查：不碰刚兑幻觉产品、不投RWA类（合规边界）、投资性房产默认不买
- [ ] 12 个月复盘：对照本方案逐条打分，输出 v2 版

**Q4 可验证里程碑**：✅ 副业年化进度≥50%（≥7万）｜✅ 定投≥9期｜✅ 复盘文档

## 5. 风险预案

| 风险 | 预案 |
|---|---|
| 答辩延期 | 全部求职动作顺延，方案冻结不取消（素材都在） |
| 两个路径都无offer | 启动纯副业过渡（专家网络+咨询），Q4 转为「再求职季」 |
| 峰位offer但需大幅降薪 | 按 P02 决策树：股权按0.4-0.6折算后计算总包，再定 |
| 矿业窗口关闭（周期反转） | E03 成本曲线法反向使用：窗口关闭=等下一轮90分位线 |
| 市场极端波动 | P04 纪律：再平衡而非恐慌操作；预期按0-8%管理 |

## 6. 本期结论

12 个月的本质是**把「选去向」从情绪决策变成闸门决策**：Q1 拿学位、Q2 拿offer、Q3 过闸门、Q4 落地成体系。全部动作都有前期研究的数字背书，全部纪律都有失败案例的来源。**最后一期 Z01 把 20 期研究拼成终稿全景地图。**
