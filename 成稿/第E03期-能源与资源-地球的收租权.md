# 第E03期 · 能源与资源——地球的收租权（超级周期）

> 《钱在哪里》全景计划 · 行业篇 实榜第4（主场期）｜ 2026-10-31 ｜ 数据时点：2025年报+2026年10月末价格
> 这是「地学博士的主场期」。本期回答：**挖矿采油的钱到底怎么分？超级周期是真命题还是叙事？** 答案：钱是租金，租金按所有权分配——国家与股东拿大头，打工人拿「位次高、增速低」的工资；所谓超级周期，必须按铜/金/锂/铀四种相位拆开看。

---

## 核心发现（30秒版）

1. **资源利润=租金，分配看所有权**：中海油桶油成本27.9美元（全球领先）与油价之间的价差就是租金——它流向国家（中石油分红860亿、BHP缴政府124亿美元）与股东（阿美2025年分配855亿美元），不流向工资单（采矿业工资增速仅1.9%、19行业倒数第三）。
2. **「超级周期」必须按品种拆**：铜14449美元/吨顶格（2026-09创历史新高）但ICSG转过剩；金3876美元高位回调（2026-01曾逼近5600）；锂二次探底（60万→5.8万→19万→10万）；铀温和上行——四种相位，一种叙事是偷懒。
3. **「利润→工资」传导在周期顶显著滞后**：2025矿业利润大增（紫金+62%、洛钼+50.3%）但管理岗年薪还在降（249123→247293元）——周期红利归股东（BHP payout 72%），不归打工人。
4. **PE陷阱可以教学化**：天齐2022年「PE最低」=锂价顶=最危险；2024年「PE失效」（亏损）=播种期；2026H1「净利暴增4935%」与「市值蒸发610亿」同框——周期股定价的是边际方向，不是已入账利润。
5. **与你最相关的一条**：地质勘查在统计上归「科研技术服务业」（182064元）而非「采矿业」（143361元）——两口径差27%，**讨论地质人收入必须先声明归属口径**。

## 三、与你最相关：资源打工人的真实钱袋

**三口径（2025年统计局+岗位分层）**：

| 口径 | 数字 | 说明 |
|---|---|---|
| 行业均值（中位代理） | **143,361元**（+1.9%，第6位） | 增速倒数第三 |
| 一线生产岗 | **120,339元** | =制造业同类的1.52倍——「下井比进厂强五成」 |
| 管理岗/技术岗 | 247,293 / 173,068元 | 管理岗同比还降了1830元 |
| 私营采矿（门槛） | **79,169元** | 约为非私营的55%——「采矿高薪」以国有大矿代言了全行业 |
| **地质勘查（口径错位）** | **182,064元**（归科研门类） | 比采矿业高27%——含设计院/检测，**系统性抬高「地质人」统计观感** |

- **利润→工资传导滞后**：紫金+62%、洛钼+50.3%的年份，采矿业工资+1.9%、管理岗降薪——**周期红利归股东不归打工人**；个人超额回报只能来自稀缺技能（海外项目、智能矿山、管理层）或股权。
- **海外对照**：澳洲采矿周薪2,740澳元≈全行业1.63倍（2017-18旧锚）；现行分项数据缺失。
- **分成比例谱系（闭环E00）**：海油约10-11%（推断）<茅台约13%<紫金待核<腾讯58%<宁德61%——**资源行业是「公司赚钱、员工少分」的典型**。

| BHP铜EBITDA 180亿美元首超集团一半、十年扩产计划 | 高盛：2026铜价回落至10,000-11,000美元 |
| 央行购金连续4年千吨级、89%央行预期继续增持 | 金价2026-01见顶后倒V；报告购金放缓「反映金价上涨的影响」 |
| 锂出清：澳矿停产+枧下窝停11个月 | 锂2023年-70~-80%的前车之鉴：需求叙事全兑现，价格照样崩 |

- **关键缺口**：「AI数据中心耗铜」至今无一手测算（「电力负载10倍」≠「铜耗10倍」）——铜的AI叙事是信念不是数据；BHP的产业行为（十年扩产）比任何研报都硬。
- **历史教训（锂）**：2021-22年「锂超级周期」共识→2023年价格崩70-80%——**需求叙事为真≠价格持续上涨**；供给弹性与政策退坡可以迅速逆转。

## 五、周期股PE陷阱：四步教学（本计划最重要的可迁移认知之一）

1. **PE最低的时刻=盈利最假的时刻**：2022年天齐PE最低——分母（159亿净利）是60万锂价的函数，而60万本身是抢货的产物。
2. **均值回归摧毁分母**：锂价60万→5.8万（-90%），天齐2024年亏79.04亿——低PE没提供任何安全边际。
3. **PE失效（亏损）时反而是底部区域**：2024-2025亏损期「看起来最贵」，定价锚换成成本曲线与重置成本；随后天齐2026H1净利+4935%。
4. **修复期≠安全期**：「净利暴增4935%」与「股价-40%、市值蒸发610亿」同框——**周期股定价锂价的边际方向，不是已入账的利润**。

> 适用边界：只对盈利与商品价同向的上游资源股成立；中游加工股（正极/电解液/电池）反向——锂价最高时它们利润被挤压。

## 六、资源租金的四口袋（BHP解剖样本）

EBITDA 330亿美元 ≈ **政府124亿**（澳洲/智利最大纳税人之一）+ **再投资103亿**（过半投铜增长项目）+ **股东87亿**（payout 72%）——成熟期矿企把2/3以上的当期钱分给国家与股东；对照紫金成长期分红率仅30%→35%。**周期阶段决定分配结构，没有「常态比例」。**

## 七、本期结论

资源行业是「**租金最厚、分配最按所有权、周期最残酷**」的行业：国家与股东拿走周期红利，打工人拿「位次高、增速低」的工资；铜金锂铀四种相位并存，「超级周期」必须按品种与时点写。**对地学博士的启示：这是你的主场，但主场的钱在三个地方——稀缺技能（海外/智能矿山/管理层）、股权（成长期矿企）、以及把周期相位读对的投资能力（PE陷阱是基本功）；纯靠工资单，你只能拿到1.9%的增速。**
