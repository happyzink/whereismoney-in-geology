# 钱在哪里 · 中国经济利润池的全景拆解

一套用**公开数据**回答「钱到底在哪里」的系统性研究：28 期，覆盖 9 个行业、6 种商业模式、4 类个人收入路径、1 次总装，外加 6 期数据分析与红队审查。

> **一句话结论**：钱不在「努力」里，在**结构**里——在成本曲线的位置、在牌照与租约、在稀缺度与期权。而三种口袋（公司的钱、股东的钱、打工人的钱）必须分开报账，混算必错。

---

## 这个项目想回答什么

1. 为什么有些行业看起来苦却不赚钱，有些看起来轻松却拿走大部分利润？
2. 同一个数字（比如「银行占全 A 净利 40%」）为什么换个口径就变？
3. 一个具体的人，站在自己的能力与约束下，该怎么选？

## 方法论

这个项目最花力气的不是找结论，是**管住结论的强度**。

### 引用契约

每个数字都带三样东西：**信度**（高/中/低）＋**时间窗**（截至何时）＋**口径**（分母是谁、含不含少数股东、是访问级还是成交级）。缺任一项，视为不可用。

正文用 `[^id]` 语义脚注，源定义紧跟所在小节：`[^id]: 标题/机构. 日期. URL`。

### 三口径纪律

同一指标永远给三个数：**头部**（最好情况）、**中位数**（典型）、**门槛**（进入最小）。只给平均数的一律视为不完整。

### 红队机制

主计划完成后，另起反方研究员**攻击而非辩护**。两轮共 22 条攻击线，最终裁决：4 条击退、5 条部分成立、4 处必须改。骨架全部存活，边缘参数全部获得误差条。

几个被改掉的例子：

| 原始说法 | 红队修正后 | 为什么 |
|---|---|---|
| 银行占全 A 净利 40.4% | 40.4% 是**下限**，统一归母口径约 42-43% | 少数股东损益占比仅约 0.6% |
| 海外定岗溢价 2-4 倍 | 本科 2.0-4.5 倍 / **博士 0.9-1.5 倍** | 分母错配：2-4 倍是本科口径 |
| 黄金 20 年年化 10.3% | **5.5-10.3%，取决于起点** | 换 2011-08 起点只剩约 5.5% |
| 长期预期 0-8% / 进取档 6-8% | **0-7% / 进取档 4-7%** | 进取档超出其成分加权上限（约 6.8%） |
| PJM 数据中心容量费占 46% | **40%** | 口径补正 |
| 平台 vs 骑手差 30-60 倍 | **28-53 倍** | 分子分母分属两家公司，拼多多没有骑手 |

### 诚实清单

拿不到的东西写「零命中 + 检索式」，不填推测。截至第 27 期，确认**结构性不可得**的有三条：省地质局绩效分配办法正文、事业单位口径的项目提成率、保 ROI 条款的司法认定。

## 边界声明

- 所有前瞻数字都是**区间推演**，不是预测。行情数据有明确时间窗（主要集中在 2026 年 10-11 月），**会过期**。
- D01/D02 是**匿名化的案例推演**，不是对任何具体个人的建议。
- 本项目不是投资建议。所有测算都已标注口径假设，请勿脱离假设引用单一数字。
- 数据来自公开渠道（财报、政府公告、交易所披露、行业报告、媒体报道），一手优先；二手转述均标注信度。发现错误欢迎提 issue。
