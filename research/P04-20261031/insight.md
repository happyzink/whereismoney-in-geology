# P04 跨维洞察（insight）

## 1. 20年回报榜的真相：黄金≈一线房产并列第一，存款垫底——但「躺赢时代已经结束」

- **主张**：2005-2025历史年化：黄金≈10.3%≈一线房产9-11%＞美股≈A股全收益8-9%＞全国房产7-9%＞存款2-3.5%；但未来预期普遍下调至0-8%——**过去20年的答案是「买房+持有」，未来20年这个答案作废，必须主动配置**。
- **跨维**：D1回报排序 + D2房产机制 + E00财产性收入。
- **支撑**：[^dive_01][^dive_02][与E00财产净收入+1.6%垫底互证]
- **反例/边界**：历史年化的口径陷阱（一线房产含杠杆收益，普通人无法复制全仓一线）。
- **Confidence**：高。
- **Implications**：E00「财产性收入是最慢的钱」的微观解释：多数人把钱放在垫底的存款里；P04给出的是「把存款搬出来」的路线图。

## 2. 房产造富三因子（货币×城镇化×杠杆）已全部反向——自住可买、投资默认不买

- **主张**：租售比1:582≈年净回报2.06%脱离租金贴现锚；人口2022年负增长；日本地价35年未回前高的镜鉴——**房产从「财富引擎」降级为「消费品+期权」**：自住看月供承受力，投资默认不买（除非租金回报率显著高于国债）。
- **跨维**：D2房产 + M02杠杆 + E00。
- **支撑**：[^dive_02]
- **反例/边界**：核心城市核心地段的稀缺性仍在（与E07真稀缺逻辑同构）。
- **Confidence**：高。
- **Implications**：D02行动方案的房产条款：毕业后3年内不投资性购房；自住决策用「月供收入比≤30-40%」（M02）+城市可买性双重闸门。

## 3. 股市的钱被谁赚走：顶层0.5%账户赚走底层85%——散户的唯一解是「不做散户做的事」

- **主张**：清华五道口4,000万账户研究：2014-15年顶层0.5%账户赚走底层85%约2,500亿元，散户的择时（-40%贡献）与选股（-60%贡献）都是负项——**个人在股市的正确姿势=宽基被动为主+股债配置（100-年龄%）+阈值再平衡，把「选择权」交给纪律**。
- **跨维**：D3股市 + E00三口径 + M05订阅（把投资也订阅化=定投）。
- **支撑**：[^dive_03]
- **反例/边界**：A股主动基金长期胜率高于美股同类——但基民收益<基金收益（行为损耗）。
- **Confidence**：高。
- **Implications**：D02资产条款：定投宽基+年度再平衡+不看盘；预期收益按0-8%规划，任何承诺高收益的产品按M02刚兑打破逻辑处理。

## 4. 低利率是新常态：现金是慢性毒药，另类有合规边界

- **主张**：存款0.95%、理财1.98%、国债1.17%、储蓄险2.0%——无风险收益率全面跌破通胀目标线；2026年2月八部门42号文把RWA/代币化资产打入禁区——**个人的收益饥渴必须用合规工具解决：宽基/黄金/REITs/储蓄险的菜单已经给全，缺的是执行**。
- **跨维**：D4低利率 + E00财产收入 + M02刚兑。
- **支撑**：[^dive_04][与E00/M05互证]
- **反例/边界**：黄金3,875美元高位（E03回调段）——配置可以，追高不行。
- **Confidence**：高。
- **Implications**：D02的三档模板直接引用；比特币等另类在中国个人配置中除名（合规优先于收益）。

## 5. 三档配置模板：把全部研究结论翻译成三张可执行的表

- **主张**：保守档（存款+国债+储蓄险为主，权益≤20%）、平衡档（宽基40%±+黄金10-15%+债30%+现金）、进取档（宽基60-70%+黄金10%+行业主题≤10%）——**每档的共同纪律：再平衡阈值±5-10pp、预期收益0-8%、不为收益突破合规边界**。
- **跨维**：D4模板 + M02安全边界 + M03成本曲线（权益仓位的周期择时）。
- **支撑**：[^dive_04]
- **反例/边界**：模板为框架非投资建议；个人应按收入稳定性调整。
- **Confidence**：中-高。
- **Implications**：D02资产条款的正文；与P02股权（0.5折算）、M02杠杆（≤50%负债率）合并成个人财务三闸门。

## 6. 与五种钱的最终闭环：资产的钱是唯一「不卖时间」的钱，但它吃认知

- **主张**：工资的钱卖时间、生意的钱卖产品、股权的钱卖未来、流量的钱卖注意力——只有资产的钱不卖时间；但E00证明多数人的资产账户是全plan最慢的钱——**差距不在本金在认知：P04全期的结论=低成本宽基+纪律再平衡+拒绝刚兑幻觉+合规边界，四条纪律值一到两个点的年化，复利20年是数倍的终值差**。
- **跨维**：全部P04 + E00五种钱 + M02/M05。
- **支撑**：[^dive_01][^dive_03][^dive_04]
- **反例/边界**：本金太小者先投资自己（P01峰位迁移的回报率高于任何资产配置）。
- **Confidence**：高。
- **Implications**：Z01总图的最终排序：**认知投资>人力资本>资产配置**——顺序不能反。
