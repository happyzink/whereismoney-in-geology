# E06 跨维洞察（insight）

## 1. 「规模与利润的赛跑」结局已分：规模越大利润越薄

- **主张**：汽车行业销售利润率4.1%（2015年以来最低、单月低至1.8%）与万亿级营收并存——制造业（除链主外）已被确认为「就业蓄水池+低利润率」行业；这与E00的宁德人均创利39万（样本末位）闭环。
- **跨维**：D1整车 + D5反面 + E00效率榜。
- **支撑**：[^dive_05][^dive_01]
- **反例/边界**：链主（宁德+42.28%、赛力斯28.8%毛利率）证明行业内部分化远大于行业均值。
- **Confidence**：高。
- **Implications**：E06的答案修正「制造业升级=制造业赚钱」的直觉——升级的是链主与设备商，不是行业平均。

## 2. 产业链的钱由链主截留：返利、账期与市占率是三种武器

- **主张**：宁德利润=二线8.4倍=材料26倍；用约20万元/吨返利换80%订单、60天账期走样——链主以规模反向定价，二线电池与材料商本质是「打工的公司」。
- **跨维**：D2电池 + D5账期。
- **支撑**：[^dive_02][^dive_05]
- **反例/边界**：宁德国内份额降至43.42%——链主地位在国内正被二线+车企自研侵蚀。
- **Confidence**：高。
- **Implications**：制造业择业的链主原则：进链主（宁德/比亚迪核心岗）吃垄断租，进二线吃周期工资——M02杠杆期的产业链版。

## 3. 出海是制造业唯一的利润出口，但关税把「出口利润」改写为「本地投资」

- **主张**：海外单车净利3倍（JPM保守口径）+比亚迪海外销量+145%证明海外的钱更好赚；但欧盟关税分档落地后，入场券变成114亿欧元级的本地建厂——出口环节利润部分让渡给欧洲（就业/税基），中国链主换取准入与定价权。
- **跨维**：D3出海 + D1整车。
- **支撑**：[^dive_03]
- **反例/边界**：本地化初期单位成本高于出口；纯电之外燃油/混动是关税漏洞通道——出口高增不能全记为新能源突围。
- **Confidence**：高。
- **Implications**：制造业个人的海外派驻经验=稀缺性溢价（与E03紫金本地化结论同构）；欧盟《工业加速法案》是下一个跟踪变量。

## 4. 机器人替代一线已经量化：一年减员9.93万、九成是一线

- **主张**：比亚迪员工86.96万→减员9.93万（九成一线）→2026年10月又破102万（结构换血）；机器人密度470台/万人——制造业打工人的钱「总量停滞、结构极化」：产线8万 vs 智驾百万。
- **跨维**：D4打工人 + D1 + D2。
- **支撑**：[^dive_04]
- **反例/边界**：2026年重新扩张至102万说明减员是结构切换而非收缩；派遣占比无官方数据。
- **Confidence**：中-高。
- **Implications**：P01/D01的制造业答案：产线岗位是机器人的替代对象，工程师与链主研发岗是仅存的上升通道；「工程师1.9×产线」的极差还会拉大。

## 5. 丰田镜鉴：中国把内卷输出成了全球利润池收缩

- **主张**：丰田利润率11.9%→7.4%——连全球最优践者也被中国价格战拉低；汽车业的低利润率不是中国特殊阶段，而是全球新均衡的第一阶段。
- **跨维**：D5反面 + D3出海。
- **支撑**：[^dive_05]
- **反例/边界**：豪华品牌与链主仍在均线上；丰田的7.4%仍高于中国全行业4.1%。
- **Confidence**：中。
- **Implications**：对出海择业者：海外工厂的岗位溢价来自「欧洲人工成本+本地化溢价」，但同样暴露在全球化价格战下。

## 6. 宁德悖论：分成最高的行业，绝对薪酬仍在低位

- **主张**：宁德劳动分成约61%（全样本最高）但人均薪酬23.63万（2024）——分成的母数（人均创利39万）太小；「高分成」是制造业的良心，「低绝对额」是制造业的天花板——两件事必须分开说。
- **跨维**：D2 + E00效率榜闭环。
- **支撑**：[^dive_02][^qq-catl-pay（E00）]
- **反例/边界**：宁德人均薪酬年增1.06万且「每月涨薪150元」，趋势向上。
- **Confidence**：高。
- **Implications**：给D01的定式：选行业的完整公式=人均创利×分成比例×个人在分工中的位置——三个因子任何一个低，工资都上不去。
