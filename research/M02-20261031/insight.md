# M02 跨维洞察（insight）

## 1. 银行是「被监管定价的杠杆机器」：ROA 0.60%的真相是薄利多转

- **主张**：银行以约10%的资本金撬动数十倍资产（工行19.54%资本充足率下仍约5倍资产/资本），赚的是「规模×0.6%」的算术——ROA 0.60% vs 美国1.12%说明中国银行用更低单位利润换更大规模；净息差1.40%是这台机器的「电费」，电费跌机器就得靠规模硬转。
- **跨维**：D1银行机制 + E01金融。
- **支撑**：[^dive_01][与E01互证]
- **反例/边界**：SVB案例证明期限错配在利率重定价下的脆弱性全球相同。
- **Confidence**：高。
- **Implications**：M02总公式之一：**金融利润=杠杆倍数×单位利差−风险成本**；三个变量任何一个恶化都由全体储户/纳税人兜底——这是牌照租金的代价。

## 2. 杠杆风险的统一模式：「杠杆+自动减仓机制+同质化持仓」=负反馈螺旋

- **主张**：2015配资股灾（1:4-5自动强平）、2022理财赎回潮（净值化破净→赎回→抛债）、2024 DMA雪球式平仓——三个市场、三种工具、同一个模式；识别要点不是杠杆倍数而是「是否存在机械化的被动卖出机制」。
- **跨维**：D2非银 + D5死亡清单。
- **支撑**：[^dive_02]
- **反例/边界**：2025年两融2.5万亿高位维保比例273.65%未现系统性爆仓——场内杠杆因保证金充足暂不触发该模式。
- **Confidence**：高。
- **Implications**：个人投资者的推论：避开任何「跌到某价位自动替你卖出」的结构（配资、高杠杆DMA产品、带强平的理财）——这是用血写成的排除清单。

## 3. 正利差杠杆创造价值，负利差杠杆是死亡倒计时

- **主张**：杠杆本身中性——恒大2.4万亿负债死于「资产回报率<负债成本率」（正利差判据的反面）；百丽LBO、房贷（利率<房产长期回报的历史区间）是正例；判断标准只有一条：借来的钱投入的资产回报是否稳定高于借钱成本。
- **跨维**：D3企业杠杆 + D4个人杠杆。
- **支撑**：[^dive_03][^dive_04]
- **反例/边界**：正利差也会死于流动性（资产对但期限错配——SVB）；判据需要留安全边际。
- **Confidence**：高。
- **Implications**：D02个人方案的核心原则：只为「回报确定的资产」加杠杆（自住房在还贷能力内）、绝不为消费加杠杆（信用卡分期的IRR是名义利率的近2倍）。

## 4. 刚兑打破是分层的：先同业、后产品、最后才轮到储户——个人要读懂自己在这条队列里的位置

- **主张**：包商（同业.toList减记）→四川信托（产品兑付4-8折）→理财净值化（2022首次负反馈）——打破刚兑的顺序是从机构间市场向零售端渐进推进；个人的钱在队列里的位置由产品合同决定，不由「银行/大机构」的牌子决定。
- **跨维**：D5死亡清单 + D2影子银行。
- **支撑**：[^dive_05][^dive_02]
- **反例/边界**：储户端仍有隐性保护的政治约束（河南村镇银行案的特例处理）。
- **Confidence**：高。
- **Implications**：D02资产配置的红线：任何「类存款但合同不是存款」的产品，都要按打破刚兑的假设定价。

## 5. 「幸存资格需逐周期重新赢得」：万科证伪了幸存者叙事

- **主张**：万科曾是中国地产杠杆纪律的代名词，2025年净负债率123.5%、巨亏885亿——行业性的负利差环境里，没有个体能靠「历史纪律」豁免；杠杆安全的评估必须每轮周期重做。
- **跨维**：D5 + D3。
- **支撑**：[^dive_05]
- **反例/边界**：招行式低杠杆策略（E01）在银行业内仍成立——行业贝塔与个体阿尔法要分开评估。
- **Confidence**：高。
- **Implications**：对个人雇主选择与投资持仓的含义：不要用「它以前没倒过」做安全判断——这条原则贯穿Z01总图。

## 6. 个人杠杆的安全边界是共识数字，不是精确科学

- **主张**：资产负债率≤50%、月供收入比≤30-40%（42%警戒）是多方共识区间；房贷3.3倍杠杆意味着房价-30%即首付归零——杠杆的可承受性最终取决于「现金流稳定性」而非净值预测。
- **跨维**：D4个人杠杆 + D3判据。
- **支撑**：[^dive_04]
- **反例/边界**：不同收入稳定性（体制内 vs 自雇）应有不同阈值。
- **Confidence**：高。
- **Implications**：D02行动方案的数字底线直接引用；与E00「财产性收入增速垫底」呼应——普通人加杠杆的正确对象只有自住房与生产性资产，且都在安全边界内。
