# M01 跨维洞察（insight）

## 1. 平台收租的四种方式，抗竞争能力排序是：金融>生态增值>广告>纯佣金

- **主张**：支付清算网络（微信0.6%费率、蚂蚁微贷）最难被侵蚀，纯佣金型（美团6-8%、携程8-10%）最易被卷；苹果30%抽成靠生态而非佣金本身——收租的护城河不在「收多少」而在「租约的退出成本」。
- **跨维**：D2单位经济 + D4全球对照 + D3半衰期。
- **支撑**：[^dive_02][^dive_04]
- **反例/边界**：Epic禁令+欧盟5% CTC证明生态租也会被监管重新定价。
- **Confidence**：高（排序为分析综合，案例各自高信度）。
- **Implications**：M02金融杠杆期与M05订阅期的共同起点——「金融化+订阅化」是平台收租的进化方向，也是监管的重点射程。

## 2. 网络效应有半衰期，失效有四个可识别的前置条件

- **主张**：场景迁移（货架→内容流：抖音3.42万亿超京东）、多归属低成本、规模不经济（社区团购亏近千亿关停）、供给可复制（贴吧月活流失九成）——四条件同时命中时，赢家通吃翻车；命中不全时，老平台进入「收缩式盈利」（微博净利+49%）。
- **跨维**：D3半衰期 + D1类型学。
- **支撑**：[^dive_03]
- **反例/边界**：社区团购的终局归类为分析判断；微信14.18亿月活证明强关系链的衰减极慢。
- **Confidence**：高（案例）/中（机制归纳）。
- **Implications**：给投资与择业的平台风险 checklist——四条件任何两个命中，平台租金进入倒计时；E02的「平台利润=竞争强度函数」在机制层的解释。

## 3. 苹果「出货20%、利润91%」：赢家通吃的数学与它的三道裂缝

- **主张**：网络效应的终局是利润集中度远超市占率；但裂缝已经出现——Epic禁令击穿美区外链佣金、欧盟降至5%、谷歌200亿美元搜索费被判可延续但监管火力全开——**生态税正在被全球监管重新定价**。
- **跨维**：D1类型学 + D4全球对照。
- **支撑**：[^dive_01][^dive_04]
- **反例/边界**：判决允许延续=租金主体仍在；欧盟5%只覆盖小范围。
- **Confidence**：高。
- **Implications**：M01的总公式：平台租金=网络效应×变现深度−监管重定价；中国「反内卷」退租潮（抖音320亿+拼多多千亿扶持）是全球同一趋势的东方版本。

## 4. 平台从「收租」转向「退租」是2025-2026的结构性转折

- **主张**：抖音为商家降本320亿、拼多多千亿扶持、苹果佣金分层、欧盟降费——平台竞争从「抽成率竞赛」转向「退租竞赛」；同期拼多多收租重心从广告转向交易抽成（E02）——**租金的「价格」在降，「结构」在向成交端下沉**。
- **跨维**：D5被抽成率 + D2单位经济 + E02。
- **支撑**：[^dive_05][与E02拼多多结构反转互证]
- **反例/边界**：降费是平台自述口径；商家体感「免佣省的<投流多的」。
- **Confidence**：高（方向）/中（幅度）。
- **Implications**：对商家/创作者：2025-2026是议价窗口期（多渠道化+私域沉淀的动作成本处于历史低位）——D02行动方案的直接输入。

## 5. 对个人：平台依赖度可用四个指标自评，私域的价值在复购不在首购

- **主张**：单渠道占比>50%即高依赖；综合被抽成率（明佣+投流+履约）才是真实成本；客户资产归属（能否免费二次触达）与迁移成本决定议价权；私域的真实价值在复购（44%关注意愿=公域1.3倍）而非首购转化。
- **跨维**：D5 + D3 + D4。
- **支撑**：[^dive_05]
- **反例/边界**：私域案例有幸存者偏差；独立站流量成本同样上涨。
- **Confidence**：高（框架）/中（数据）。
- **Implications**：D01/D02个人方案的可执行工具；P03副业期的选平台决策树基础。

## 6. 平台依赖度的终极形态：AI助手正在对「入口租」发起十年级替代

- **主张**：豆包3.45亿/千问1.66亿/DeepSeek 1.27亿月活——AI对话是继货架→内容流之后的下一次场景迁移；搜索平台（百度29.44%桌面份额且被必应反超）是第一个被命中「场景迁移」条件的旧租客。
- **跨维**：D3半衰期 + D1类型学 + E04应用层。
- **支撑**：[^dive_03][与E04互证]
- **反例/边界**：「百度搜索量暴跌70%」低信度；AI助手的商业变现尚未闭环。
- **Confidence**：中。
- **Implications**：M05订阅与E04 AI的交叉预测：入口租的下一轮洗牌在AI——个人与企业的「被搜索/被推荐位」资产需要重估。
