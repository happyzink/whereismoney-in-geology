# P03 跨维洞察（insight）

## 1. 副业的第一课是「不做」：全成本时薪低于主业×0.5的副业是负资产

- **主张**：自媒体起步期时薪约0-5元/小时（低于最低工资）；临界点判据=主业时薪×0.5——一个主业时薪100元的人，做时薪30元的副业是在用负利差燃烧时间；**副业的正确起点不是「做什么」而是「不做什么」**。
- **跨维**：D2时间经济学 + D1形态盘点。
- **支撑**：[^dive_02][^dive_01]
- **反例/边界**：复利型副业（内容沉淀/技能复利）起步期时薪必然低——判据应给12-24个月观察期。
- **Confidence**：高。
- **Implications**：D02行动方案的第一条：先做时间审计（三来源），再筛副业形态。

## 2. 高学历副业的峰值在「专家网络」：时薪约1,300元/小时的合规套利

- **主张**：凯盛/GLG类专家网络的专家时薪约1,280-1,330元/小时——把博士的行业认知按小时卖给投资机构，是高学历者时薪最高的合规副业；天花板是「认知每小时的单价」，与M04信任密度同构。
- **跨维**：D3赛道 + M04四模式 + P01峰位。
- **支撑**：[^dive_03]
- **反例/边界**：合规红线（不得泄露任职公司机密）；冷门领域供需不匹配。
- **Confidence**：中-高。
- **Implications**：地学博士的专家网络切入点：矿业/新能源金属/碳中和——正好是E03/E04验证过的资本热点领域；D02行动清单的直接动作项。

## 3. 伪副业的识别公式：「上游收入=下游学费」

- **主张**：教你做副业的人赚的是你的学费（割韭菜的定义式）；中消协副业类投诉均额超7,000元——**凡是「先交钱学怎么赚钱」的，大概率是那7,000元的一员**；真副业的门槛是技能与时间，不是学费。
- **跨维**：D1盘点 + M04三口径 + E07三口径纪律。
- **支撑**：[^dive_01]
- **反例/边界**：正规技能培训（编程/设计课）与「副业暴富课」的分界在是否有可验证的就业/收入结果。
- **Confidence**：高。
- **Implications**：D02的防坑清单第一条；也是本计划对读者最重要的自我保护提示。

## 4. 税务是副业的隐藏杠杆：同样20万年收入，路径选对税差30倍

- **主张**：劳务报酬（>30%）vs 个体户查账（约11%）vs 个独核定（<1%但属偷税）——**合规地选择收入性质是副业利润率最大的单一变量**；分界线：持续性商单/带货注册个体户（月销10万增值税免税叠加），单次劳务个人承接。
- **跨维**：D4法律税务 + M04四模式。
- **支撑**：[^dive_04]
- **反例/边界**：个独核定已被稽查定性为偷税——低税负路径的合规性比税率更重要。
- **Confidence**：高。
- **Implications**：D02合规清单：副业月收入稳定超5,000元即应考虑注册个体户；公务员红线（第五十九条）为不可触碰项。

## 5. 平台账号是租用资产：副业资产化必须「去平台化」

- **主张**：平台账号不可迁移、封号即归零（与M06人格折价80%同构）——副业的资产化路径=把平台流量沉淀为「自有触达」（邮件列表/微信群/个人网站），M01四指标自评的实操版。
- **跨维**：D4风险 + M01平台依赖 + M04商单。
- **支撑**：[^dive_04][与M01/M06互证]
- **反例/边界**：私域的维护成本（触达率衰减）。
- **Confidence**：高。
- **Implications**：D02副业启动清单：第一天就建自有触达渠道，不要等到有粉丝才建。
