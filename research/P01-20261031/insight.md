# P01 跨维洞察（insight）

## 1. 选行四象限：钱多与在涨是两个维度，最优解在第一象限且进入成本可承受

- **主张**：IT/科研落在「钱多且在涨」，采矿/金融「钱多但强周期或收缩」，多数人困在「钱少且收缩」象限而不自知——选行的第一步是识别自己所在的象限，第二步计算迁移的进入成本。
- **跨维**：D1选行 + E00行业榜 + E03/E04/E05行业期。
- **支撑**：[^dive_01]
- **反例/边界**：强周期行业的周期顶（E03资源）可以在特定窗口跑赢一切——象限是静态，窗口是动态。
- **Confidence**：高。
- **Implications**：P01的矩阵直接进D01；地学博士的五条赛道打分（采矿/科研/环保/IT/金融）是D01的骨架。

## 2. 峰位岗位的半衰期是2-4年：峰位会迁移，硬门槛子岗不会消失

- **主张**：AI岗从2022稀缺到2026泡沫收缩（半衰期2-4年），但峰位没有消失而是向「硬门槛子岗」迁移（大模型算法→推理优化/技术美术/领域AI）——追逐峰位的正确姿势是追「峰位背后的硬门槛」，不是追岗位名。
- **跨维**：D2峰位 + E02 AI岗 + M04专业人设。
- **支撑**：[^dive_02]
- **反例/边界**：量化岗的硬门槛（数学+代码+ 金融知识三重）使其半衰期更长。
- **Confidence**：高。
- **Implications**：博士的「最近峰位」选择树（D2产出）直接进D01：硬门槛与你的博士训练重叠度最高的那个峰位，就是你的最优迁移目标。

## 3. 选城的账本：一线溢价收窄到15-30%，而房价收入比差2-4倍——新一线是套利区

- **主张**：38城均值10,115元 vs 上海13,492元——一线溢价15-30%；但核心区房价收入比一线25-27倍 vs 新一线显著更低——「薪酬打折、房价打折更多」；叠加杭州博士10万/余杭13万/苏州1,500元月补的人才政策，**新一线+补贴是风险调整后的中间最优解**。
- **跨维**：D3选城 + D4体制内 + E02大厂分布。
- **支撑**：[^dive_03]
- **反例/边界**：10年尺度的收入曲线斜率一线更陡（岗位密度与晋升天花板）；体制内估算信度低。
- **Confidence**：中-高。
- **Implications**：D02行动方案的选址建议：除非拿到峰位岗（AI/量化），否则新一线+补贴优于一线硬漂。

## 4. 体制内的真实定价：军队文职是唯一透明的「高值标价岗」，其余全靠拼图

- **主张**：军队文职本科到手约9,000元/月是全国唯一统一定价的透明口径；公务员分部委/省直/强区/县乡四档（强区峰值28-30万依赖年终绩效）；事业专技高端32-60万——**体制内不是一个市场，是四十个市场**；地质队是证据断层地带（全计划最大口径缺口）。
- **跨维**：D4体制内 + E00口径五陷阱 + E03地勘归属。
- **支撑**：[^dive_04][与E00/E03互证]
- **反例/边界**：强区年终绩效有不稳定性；职业年金 vs 企业年金的退休端差异是量化尝试（推断）。
- **Confidence**：中-高（档位框架）/低（具体数字）。
- **Implications**：D01的体制内板块必须按「地区×层级」四档矩阵呈现，并显式标注地质队为「待内部人碎片」——诚实比完整更重要。

## 5. 退休端是体制内全包的隐藏项：职业年金 vs 企业年金的覆盖率差

- **主张**：体制内职业年金为强制建立（单位8%全缴），企业年金覆盖率极低——退休端的差异使体制内的「终身全包」比当期工资差距显示的更接近大厂；量化尝试为推断，方向可信。
- **跨维**：D4 + E01金融薪酬。
- **支撑**：[^dive_04]
- **反例/边界**：年金投资收益不确定；延迟退休改变领取贴现。
- **Confidence**：中。
- **Implications**：D01比较「体制内 vs 企业」时的完整公式：当期全包 + 退休端差异 + 稳定性溢价 − 成长性损失。

## 6. 博士的「最近峰位」选择树：用训练重叠度选峰位，用半衰期选时机

- **主张**：D2产出的选择树把7族峰位按「与博士训练的重叠度」排序——地学博士的重叠度排序大致为：量化（数理）≈领域AI（地学大数据）> 芯片材料 > 医药研发（分析化学相邻）> 券商行研（有色组）——**每个峰位的半衰期决定迁移时机：在峰位成熟期进入（2-4年窗口），在泡沫期避开**。
- **跨维**：D2峰位 + E02/M04峰位 + E03/M03主场。
- **支撑**：[^dive_02]
- **反例/边界**：选择树为框架，个案需实测（面试+offer）。
- **Confidence**：中-高。
- **Implications**：D01的核心工具直接引用；与「主场溢价」（M03）合并成D01的双引擎：主场租金+峰位迁移。
