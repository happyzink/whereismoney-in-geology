# P02 跨维洞察（insight）

## 1. RSU的现金等价只有账面的40-60%：招聘offer上的「总包」需要两步修正

- **主张**：以字节实测回购价为锚，概率（IPO 25%权重）×稀释（10-15%）×归属（4年）×离职折扣（10%）×税（35%）×时间折现（15%）后，RSU期望值仅为账面40-60%——**看offer先做两步修正（概率加权+时间折现），否则系统性高估收入约一半**。
- **跨维**：D1期望值 + E02五机制。
- **支撑**：[^dive_01]
- **反例/边界**：早期入职者（低基数）的倍数逻辑不同；上市公司RSU折价较小（0.7-0.85）。
- **Confidence**：高（模型与假设全部显性化，可复算）。
- **Implications**：D01/D02的谈判工具：任何offer先问股数、当前回购价、归属节奏，按0.4-0.6系数折现后再比。

## 2. 定价权在雇主：招聘价与回购价脱钩是晚期入职者的结构性劣势

- **主张**：字节招聘价上调13%至226.07美元而回购价停在200.41——晚期入职者以接近公允价的成本买入流动性极差的准债券；早期入职的优势=低基数×同一退出价。
- **跨维**：D1 + E02归属机制。
- **支撑**：[^dive_01]
- **反例/边界**：若IPO溢价50%+兑现，晚期入职者也有空间——但那是高方差项。
- **Confidence**：高。
- **Implications**：跳槽谈判时「上一家的RSU按账面折算」是对公司有利的错误——坚持按0.5-0.6折算。

## 3. 套现规则的窗口差：港股是员工最友好的市场，A股解禁日才是期望值口径

- **主张**：港股仅锁控股股东6个月、员工归属即可卖（2025年窗口开盘均益约40%）；A股大股东受限+2026年81只破发+1.7万亿解禁——**同一份RSU在不同市场的期望值完全不同**；老铺黄金+230%是「窗口+真稀缺」的公开造富样本。
- **跨维**：D2套现 + E07老铺 + E08游戏出海。
- **支撑**：[^dive_02]
- **反例/边界**：破发的81只提醒「上市≠造富」。
- **Confidence**：高。
- **Implications**：选offer时的隐藏变量：公司的上市地与窗口期——港股已上市的>港股待上市>A股待上市>不上市。

## 4. 优先清算权：退出时普员工排在所有人后面，小额度退出你可能一分拿不到

- **主张**：1x非参与清算权下，5,500万-8,000万美元的退出区间内普员工实得为名义值的0-55%——投资人先拿回本金，剩余才轮到普通股；非上市期权行权日即缴税、无回购则死锁。
- **跨维**：D3陷阱 + D4决策框架。
- **支撑**：[^dive_03]
- **反例/边界**：大额退出（10亿美元+）时清算权影响变小。
- **Confidence**：高。
- **Implications**：offer必问清单的第一问：「公司清算优先权倍数是多少、已融资多少」——决定你的期权在什么退出规模下才开始值钱。

## 5. 默认答案是不为股权降薪：期望值转正只有三个场景

- **主张**：Carta口径近半种子公司4年内未晋级A轮、员工行权率仅28-32%——初创期权的基准期望值为负；转正仅发生在：①你是技术合伙人（股权比例够大）②硬科技早期（稀缺技术入股）③有回购的Pre-IPO（下行保护）。
- **跨维**：D4决策框架 + D1期望值 + M02杠杆判据。
- **支撑**：[^dive_04]
- **反例/边界**：对现金流充裕、追求上行的人，小额降薪换期权是可接受彩票。
- **Confidence**：高。
- **Implications**：D02行动方案的决策树：博士的offer评估默认「股权按0.5折算且不为它降薪」，除非命中三个转正场景之一；offer必问五问直接列进行动清单。

## 6. 与全景的连接：股权的钱是「五种钱」里方差最大的一种

- **主张**：对照M04（创作者收入右偏）与E08（独立游戏95%亏损），股权期权的分布更极端——它是「用确定性的现金薪资换取一张概率彩票」；E00「存量看股权」的结论在个人层面的精确表述是：**股权造富真实存在，但它是对幸存者的结算，不是对参与者的期望**。
- **跨维**：D1 + E00五种钱 + E07老铺。
- **支撑**：[^dive_01][与E00/E07互证]
- **反例/边界**：字节类「准债券型RSU」（年化12%可回购）方差小得多——区分「彩票型期权」与「债券型RSU」是谈判第一步。
- **Confidence**：高。
- **Implications**：Z01总图个人篇的定稿句：股权的钱更多，但它属于能识别分布并谈判的人。
