# E03 跨维洞察（insight）

## 1. 资源行业的钱是「租金」，租金按所有权分配——不按劳动分配

- **主张**：油气的利润主体不是「人干的活」，而是成本线（海油桶油27.9美元）与油价之间的资源价差；它流向国家（中石油分红860亿、BHP缴政府124亿美元、智利权利金）与股东（阿美分配855亿美元），工资单只按劳动力市场定价（采矿业+1.9%倒数第三）。
- **跨维**：D1油气 + D2矿业 + D3打工人 + D5钱流图。
- **支撑**：[^aramco-fy2025][^bhp-ar2026][^eastmoney-petro][^stats-nbs-2025]
- **反例/边界**：采矿一线120339元=制造业1.52×说明市场已部分定价艰苦与风险；外包劳务使全口径劳动成本高于「员工薪酬」口径。
- **Confidence**：高。
- **Implications**：「进矿业分享超级周期」的期望要校准——周期红利默认归国家与股东；个人的超额回报只能来自稀缺技能（海外项目、智能矿山、管理岗）。

## 2. 同一个「超级周期」里藏着四种不同的周期相位

- **主张**：铜（价格顶格+平衡表转松的顶部特征）、金（历史高位后倒V回调+央行结构买盘）、锂（二次探底+出清未完）、铀（温和上行未过热）——「矿业=单一超级周期」是叙事偷懒，必须按品种拆开。
- **跨维**：D2矿业 + D4锂 + D5争论。
- **支撑**：[^westmetall-cu][^te-gold][^eastmoney-锂][^ans-铀][^recyclingtoday-icsg]
- **反例/边界**：ICSG账面过剩与现货升水矛盾；央行购金报告值与估计值口径差。
- **Confidence**：高（分品种事实）/中（相位判断）。
- **Implications**：给个人的资源行业择时框架：看品种相位而非行业叙事；E03结论直接服务D01的矿业窗口判断。

## 3. 周期股的PE陷阱可以教学化：「PE最低=最危险，PE失效=播种期」

- **主张**：用锂矿四步讲透——2022年天齐PE最低（分母是60万锂价的假象）→均值回归摧毁分母（2024亏79亿）→PE为负时才是底（2025）→修复期不等于安全期（2026H1净利+4935%与市值蒸发610亿同框）。
- **跨维**：D4锂 + D2估值方法。
- **支撑**：[^21jingji-2022][^sina-tianqi-2024][^tmtpost-tianqi-202607]
- **反例/边界**：只适用于盈利与商品价同向的上游资源股；中游加工股反向。
- **Confidence**：高（案例）/高（方法）。
- **Implications**：这是全计划最重要的可迁移理财认知之一，直接进Z01总图与D02行动方案。

## 4. 「利润→工资」传导在周期顶显著滞后：矿业版「三种口袋」的量化注脚

- **主张**：2025年矿业利润弹性（紫金+62%、洛钼+50.3%）几乎全部落在股东端（BHP payout 72%、力拓中期息+43%），工资端只爬坡1.9%、管理岗还在降薪——周期顶放大人均创利、摊薄劳动分成（海油约10-11%推断）。
- **跨维**：D3打工人 + D2矿业 + D5四口袋。
- **支撑**：[^stats-nbs-2024][^stats-nbs-2025][^bhp-ar2026][^mfam-rioH1]
- **反例/边界**：外包劳务口径、艰苦岗位风险溢价、海外本地化用工96%的紫金结构。
- **Confidence**：高。
- **Implications**：与E00发现（海油8-11% vs 宁德61%）闭环——资源行业的「公司赚钱、员工少分」是结构性的；个人答案是稀缺技能溢价或股权，不是工资。

## 5. 供给瓶颈（17.9年）是铜多头最硬的牌，但「AI耗铜」还缺定量环节

- **主张**：新矿从发现到投产平均17.9年且仍在拉长——铜的供给约束是真结构性；BHP铜EBITDA 180亿美元首超集团一半、给出十年扩产计划是产业资本的行为验证；但「数据中心铜耗」至今没有一手测算——AI叙事对铜的增量贡献仍是信念而非数据。
- **跨维**：D5争论 + D1 capex（E04交叉）。
- **支撑**：[^spglobal-leadtime][^bhp-ar2026][^investing-copperai]
- **反例/边界**：ICSG转过剩、高盛预测2026回落至10000-11000美元；钠电/少铜化技术路线。
- **Confidence**：高（供给）/中（AI需求）。
- **Implications**：E04电力洞察的姊妹篇——AI的钱流向实物世界的出口=铜+电力设备；但用铜做投资判断要盯2027年平衡表，不要盯叙事。

## 6. 资源民族主义改变的是租金分配，不是资源的存在

- **主张**：智利加税+国家控股锂、印尼配额反复、巴拿马关停（GDP预测6%→1%）、布基纳法索国有化——国家正在上收租金；但智利同期832亿美元投资管道照常推进——资本没走，只是议价权向资源国倾斜。
- **跨维**：D5 + D2 + D4（配额经济学）。
- **支撑**：[^codelcosqm][^riotimes-chile][^spglobal-nickel][^mining-cobrepanama][^trade-chile]
- **反例/边界**：配额反复（印尼一年内三次调整）本身制造价格波动，政策既是租金工具也是扰动源。
- **Confidence**：高。
- **Implications**：中国企业的海外资源战略（紫金模式：持股+本地化用工96%）是对冲资源民族主义的范式；对个人：海外项目经验是矿业职业的稀缺性溢价来源。
