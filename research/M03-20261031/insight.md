# M03 跨维洞察（insight）

## 1. NAV实算证明：紫金的市值没有定价「高铜价持续」，只定价了「产量」

- **主张**：用紫金自己的2026年产量指引+中性价格假设算出的NAV（约7,700-7,800亿元）与市值（7,812亿）基本吻合——隐含长期铜价约11,000美元/吨，比现货顶格价14,449美元低24%：**市场用脚投票选择了E03的反方（价格均值回归）**。
- **跨维**：D1 NAV + E03四相位。
- **支撑**：[^dive_01]
- **反例/边界**：NAV对长期价格假设高度敏感（±20%→±10-20%）；若铜的结构性短缺兑现，当前市值反而是低估。
- **Confidence**：高（方法）/中（结论）。
- **Implications**：给投资矿业股的可操作框架：自己算NAV、写明价格假设，再看市场隐含假设与自己的差异——这是矿业投资的「安全边际」计算器。

## 2. 成本曲线90分位线是资源品的价格地板——两轮周期实证成立

- **主张**：2016年铜底1.94美元/磅正好击穿当时C90成本线；锂价5.8万元/吨（2025-06）同样落在高成本产能现金成本区——价格底=边际产能的现金成本，这是成本曲线定位法的核心，比任何叙事都硬。
- **跨维**：D3择时 + E03锂周期。
- **支撑**：[^dive_03]
- **反例/边界**：顶部没有对称规律（顶由需求脉冲决定，底由成本曲线决定）。
- **Confidence**：高。
- **Implications**：矿业投资的第一规则：**在90分位成本线附近买入，在高分位成本产能大量复产时卖出**；D02个人资产配置直接引用。

## 3. 巨头的阿尔法全部来自逆周期并购：买在行业现金流最差的年份

- **主张**：紫金卡莫阿（2015）、洛钼TFM（2016）都买在铜价与行业现金流的底部；藏格（2025年137亿）买在锂价二次探底后——**逆周期并购的买点=行业现金流最差+资产负债表最干净的玩家出手**。
- **跨维**：D3择时 + D4资本配置 + E03。
- **支撑**：[^dive_03][^dive_04]
- **反例/边界**：逆周期并购需要逆周期的资产负债表——这是「平时少分红多留现金」的代价。
- **Confidence**：高。
- **Implications**：矿业职业的启示：并购整合能力是矿业公司最稀缺的岗位技能（地质+财务+跨文化）——对地学博士是最高溢价的方向之一。

## 4. 矿权是「百倍跃迁」的实物期权：从探矿权到采矿权的制度性价差

- **主张**：瓦石峡南锂矿起拍1,580万成交60.88亿（385倍）、斯诺威起拍335万成交20亿（597倍）——探转采的价值跃迁来自「资源从地质事实变为法律确认的资产」；新《矿产资源法》竞争性出让+2-4%出让收益率把这张门票制度化了。
- **跨维**：D2矿权 + M02杠杆（矿权是天然期权）。
- **支撑**：[^dive_02]
- **反例/边界**：跃迁的前提是勘探成功——多数探矿权归零；Bre-X式储量注水是永恒的造假形态。
- **Confidence**：高（案例）/中（推广性）。
- **Implications**：对地质人最直接的启示：**勘探环节的期权价值被制度性低估**——懂地质+懂评估准则（CMVS）的人在矿权交易链条上有天然的信息优势；这是D01定位期「主场溢价」的最硬证据。

## 5. 矿业资本配置的决策树：分红率由项目管线回报率决定，不由身份决定

- **主张**：BHP payout 72%是因为它没有好项目可投；紫金ROE 33%只分35%是因为再投资回报远超股东机会成本——判断矿业公司好坏的唯一财务问题是：「留存的每一块钱能产生高于股东自己投资回报的项目吗？」附六条红旗（高价并购/勘探支出资本化/储量突然上修/关联交易/超lend capex/频繁改名）。
- **跨维**：D4配置 + D1 NAV + E03四口袋。
- **支撑**：[^dive_04]
- **反例/边界**：智能矿山capex正在改变回报结构（自动化对成本的削减）。
- **Confidence**：高。
- **Implications**：Z01总图的矿业板块结论：**矿业投资=买管理层的资本配置能力，不是买商品价格**。

## 6. 对地学博士的专属结论：主场的钱在三个估值与定价环节

- **主张**：把E03（行业事实）、M03（估值机制）合并，地质背景的溢价位在：①勘探成功率的判断（矿权期权定价的信息优势）；②储量/成本曲线的专业核验（NAV与PE陷阱的输入质量）；③逆周期并购的标的筛选（行业人脉+技术尽调）——三者的共同点是**信息不对称所在处**。

- **支撑**：[^dive_01][^dive_02][^dive_03][^dive_04]
- **反例/边界**：纯技术背景需要补金融与交易能力（M02判据+本NAV方法）才能兑现溢价。

- **Implications**：D01定位篇的主场结论提前锚定：**转金融（矿业基金/券商有色组）或留在产业（并购/评估岗）都比纯技术岗更靠近租金分配环节。**
