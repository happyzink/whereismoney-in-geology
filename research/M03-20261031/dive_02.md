# Dimension 02: 矿权定价机制——从探矿权到现金流的门票

## Dimension 02: 矿权定价机制（探矿权取得 → 税负 → 国际对照 → 转让增值 → 评估与造假）

### Current State

- 中国矿业权取得制度已完成"申请在先→竞争性出让"的制度切换：2024年11月8日修订、2025年7月1日施行的新《矿产资源法》第十七条首次在法律层面确立"招标、拍卖、挂牌等竞争性出让为主、协议出让为补充"的原则 [^mnr-mineral-law] [^deheng-competing]。协议出让仅限国务院确定的具体项目等法定例外情形。
- 探矿权→采矿权实行"探转采"制度：新矿法第二十五条规定"探矿权人探明可供开采的矿产资源后可以在探矿权期限内申请将其探矿权转为采矿权"，且需重新签订出让合同、补缴出让收益差额 [^mnr-mineral-law]。
- 门票价格 = 一次性"矿业权出让收益"（招拍挂成交价）+ 逐年按销售收入的"出让收益率"征收：财综〔2023〕10号《矿业权出让收益征收办法》明确"矿业权出让收益＝探矿权（采矿权）成交价＋逐年征收的采矿权出让收益；其中，逐年征收的采矿权出让收益＝年度矿产品销售收入×矿业权出让收益率" [^mof-caizong10]。按矿业权出让收益率征收的矿种目录（试行）覆盖石油、天然气、铜、金等主要矿种，收益率大体在2%–4%区间（如铜、金为3%档，石油天然气2%–4%按矿种/区块确定）[^jilin-tax-caizong10]。
- 在"一次性成交价"之外，各地还需执行自然资源部2023年10月印发的《矿业权出让收益市场基准价制定指南》，基准价是招拍挂的底价锚 [^np-benchmark-price]。
- 典型价格量级：普通矿种探矿权招拍挂成交价可低至百万元级（自然资源部口径2018年12月全国探矿权出让2宗、成交总额仅173万元）[^shumx-201812]；而高景气矿种（锂）在招拍挂中可拍出60亿元级天价——2023年2月新疆若羌"瓦石峡南锂矿勘查探矿权"挂牌，起拍价1580万元，最终成交价约60.88亿元 [^solarbe-lithium]；司法拍卖口径下，2022年5月四川雅江斯诺威矿业54.2857%股权（对应锂矿权益）起拍价335万元，鏖战五天五夜以超20亿元成交 [^ifeng-snowridge]。
- 中国矿业企业实际税负 = 资源税 + 矿业权出让收益（权利金性质）+ 所得税：资源税按《资源税法》（2020年9月1日施行）税目税率表从价计征，金属矿产税率普遍在2%–8%区间（如铁矿石8%、铜矿7%上限档，具体税率由省级在幅度内确定）[^jmwl-tax-table]；头部矿企紫金矿业2025年利润总额808.68亿元、归母净利润518.62亿元 [^zjky-2025perf]，所得税+资源税等"四口袋"中政府口袋占比约四成，与BHP FY2026基础EBITDA 329亿美元中政府拿走124亿美元的结构互为镜像。
- 权利金（royalty）国际对照：智利2023年12月通过新采矿权利金法，对年产铜超5万吨（销售超5万吨金属量）的企业征收1%从价（ad valorem）+ 按营业利润边际递进的从利润税，综合最高边际税率可达32% [^ey-chile-royalty] [^iea-royalty]；澳大利亚按州征收权利金，西澳金为2.5%（并可随金价浮动调整，2026年9月金价口径下为"royalty value的2.5%"）[^wa-royalty]，澳洲矿业2023-24财年合计缴纳权利金269亿澳元 [^minerals-council]；非洲刚果（金）2018年新矿业法将铜、钴权利金从2%提高到3.5%，战略矿产（钴被列为战略矿产）可达10% [^jdsupra-drc] [^oxfam-drc]。
- 矿权转让市场的价值跃迁：一张探矿权升值为采矿权/矿山的倍数在景气矿种上可达百倍至千倍量级——瓦石峡南锂矿探矿权成交价60.88亿元 vs 起拍价1580万元（约385倍，且起拍价本身已是基准价的数倍）；斯诺威股权20.07亿元 vs 起拍335万元（约600倍，注意口径为股权非矿权本体）[^solarbe-lithium] [^ifeng-snowridge]。司法拍卖溢价的核心逻辑：探矿权证只是"勘探许可"，其估值锚是未来采出矿产品的现金流贴现，价格弹性完全由金属价格驱动——2021–2023锂价暴涨期出现的溢价，在2024–2025锂价二次探底（碳酸锂93,300元/吨）后同批资产已出现流拍与减值（推断，见Tensions）。
- 评估准则体系：中国矿业权评估师协会（CMVA）发布九项准则（《矿业权评估技术基本准则》《矿业权评估程序准则》《收益途径评估方法规范》《成本途径评估方法规范》等）[^shanghai-cmva]，配套指导意见编号如 CMVS 30300-2010《评估利用资源储量的指导意见》、CMVS 30900-2010《利用企业财务报告指导意见》[^chinasd-cmvs] [^sina-huayu]。收益途径（DCF）是探转采与出让收益评估的主流方法，折现率与储量参数是估值最敏感的两个旋钮。
- 常见造假点：①储量注水/品位调整——调整边界品位、把推断资源量（Inferred）包装为控制/探明级别直接进入DCF产量模型；②采样造假——Bre-X布桑金矿案为世纪标本：1995–1997年编造的"世界最大金矿"实为在岩芯样品中加入金粉，股价暴涨600倍后崩盘归零 [^moomoo-brex] [^zhihu-brex]；③DCF参数操纵——压低折现率、拉长服务年限、低估选矿回收率之外的AISC成本；④"探转采"时间与权益金差额在评估中被弱化，导致矿权估值虚高。

### Tensions & Counter-arguments

1. **资源税率引用等级不足**：铜7%、铁8%来自二手转述页面[^jmwl-tax-table]，《资源税法》税目税率表为幅度税率且"具体适用税率由省级提出报同级人大常委会决定"，各省实际执行税率差异大；正式引用前必须对照《资源税法》附件税目税率表原文核验（待证）。
2. **天价锂矿的幸存者样本问题**：60.88亿与20亿案例均发生在2022–2023锂价历史顶部，2024–2025碳酸锂二次探底（93,300元/吨）后同类资产出现流拍、并购重议价与减值；"百倍/千倍跃迁"是景气顶部的极端分位，不能当作长期期望倍数（推断，属口径警示）。
3. **中国"出让收益率"≠国际royalty**：财综10号的2%–4%收益率仅是权利金近似物，中国矿企另缴资源税（2%–8%）+25%所得税，三费叠加后综合政府口袋比例与智利32%上限、澳洲州royalty+30%公司税的横向比较需统一到"政府提取总额占EBITDA比"口径，否则跨国会高估或低估中国税负（推断）。
4. **斯诺威口径失真**：600倍溢价是"股权拍卖+锂价顶峰+债务/产能指标附随价值"的合成结果，直接当作"探矿权升值采矿权倍数"会夸大；瓦石峡南案例（探矿权本体）更干净，但385倍中包含资源量从"推断"升级的预期。
5. **矿业权出让基准价各地不一**：2025年12月自然资源部办公厅发文要求"矿业权出让底价应遵循市场规律……不得低于矿业权出让起始价"（湖南省政府网转载）[^hunan-dijia]，各省基准价差异可达数倍，"典型价格量级"只能是区间而非单点。
