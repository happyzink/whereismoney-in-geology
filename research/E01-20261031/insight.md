# E01 跨维洞察（insight）

## 1. 银行的真相是「高集中度 + 低利润率」的组合，不是"暴利"

- **主张**：银行占A股四成净利（集中度支持牌照论）与ROA仅0.60%、息差1.40%低于"生命线"（利润率支持风险补偿论）同时成立——"银行赚走实体多少钱"的争论双方各对一半。
- **跨维**：D1银行 + D5政治经济学。
- **支撑**：21749亿/40.4%[^bjcb-42bank]；ROA 0.60%/ROE 7.78%/拨备7.2万亿[^nfra-2025q4]；制造业利润56916亿=银行2.4倍[^stat-gov-gongbao]。
- **反例/边界**：两套口径（上市结构 vs 行业总量）回答的是不同问题，不可互相驳斥。
- **Confidence**：高。
- **Implications**：E01结论直接修正大众叙事——"进银行分暴利"是错觉，银行打工人分的是"330万亿资产的杠杆账"里的固定工资。

## 2. 金融子行业利润分层极端：管钱的规模 ≠ 赚钱的能力

- **主张**：银行2.4万亿 >> 保险4253亿 > 券商2194亿 >> 信托289亿——信托管着32万亿资产只赚289亿（约万分之九的资产收益率），牌照类型决定利润池深浅。
- **跨维**：D1 + D2 + D3。
- **支撑**：各子行业净利（见verify高信度3/4/6）；大资管总盘子184.53万亿。[^xinhuanet-ziguan-184]
- **反例/边界**：券商保险在牛市年利润弹性极大，分层会随市场状态摆动。
- **Confidence**：高。
- **Implications**：选金融细分赛道的顺序（银行>保险>券商>>信托）本身就是"钱多钱少"的答案；M02金融杠杆期的核心案例。

## 3. 券商是纯β生意：牛市印钞、熊市绞肉，佣金率已无缓冲垫

- **主张**：2025年成交额+逾六成传导为经纪+42.5%、净利+43.75%（利润增速远超营收增速=经营杠杆）；同一机制在2018/2022反向运转；净佣金率万分之二的历史低位使下行期无对冲空间。
- **跨维**：D2券商 + D4从业者。
- **支撑**：[^zhongzhengxie-2025yingxiao][^dfcfw-yjbg-2025]；"高管降6.03% vs 员工涨"的2025年回暖即β的薪酬端体现[^14]。
- **反例/边界**：财富管理/ETF（6万亿）等非方向性业务在提升利润稳定性。
- **Confidence**：高。
- **Implications**：金融从业者的奖金是β——选券商=接受收入随行情巨摆；对个人是"高期望值×高方差"的职业。

## 4. 保险2025年的利润是镜子，不是面包

- **主张**：+22.4%的新高主要是权益浮盈按新会计准则直接进利润表——平安Q4单季-74.1%证明其不可持续；利差损存量是十年级问题，预定利率2.0%只关住了新单。
- **跨维**：D3保险 + D5。
- **支撑**：[^21jingji-wuda-nianbao][^dongwu-pingan-dianping][^sp-xinping-zhiliang]；理财收益率1.98%<新单预定利率2.0%的倒挂缓解。
- **反例/边界**：平安归母营运利润+10.3%显示经营基本盘尚稳。
- **Confidence**：高。
- **Implications**：保险股的"便宜"与保险代理人的"高收入叙事"都要打折看；分红险转型是行业自救主线。

## 5. 金融打工人的钱三层撕裂：头部与门槛差20倍，限薪令只压高管

- **主张**：券商人均111.76万 vs 银行柜员到手月薪5千-1.2万（年化约7-15万）；限薪令压高管（-45%）不压员工（九成涨薪）；校招三连降（7.76万→6.4万岗）但存量微增——金融业的入口在收窄、存量在转型。
- **跨维**：D4从业者 + D1银行。
- **支撑**：[^4][^6][^13][^14][^17][^19]。
- **反例/边界**：门槛端数据信度低（招聘网站口径）；总行岗vs基层级差无官方披露。
- **Confidence**：中-高。
- **Implications**：「进金融」必须问三个问题：什么牌照（银行/券商/保险）、什么岗位（前台/中后台）、什么入口（校招连续收缩）——P01职业矩阵的关键输入。

## 6. 未来十年银行利润池大概率名义停滞（0-2%）：金融的钱途在非息，不在利差

- **主张**：息差年降5-8bp的趋势下，银行利润池十年名义复合增速0-2%（低置信推算）；股票融资占比2.8%说明直接融资替代缓慢——金融业个人"钱途"的增量在财富管理/投行/量化等非息条线。
- **跨维**：D5政治经济学 + D2券商。
- **支撑**：NIM 1.42%→1.40%[^yicai-nim]；股票融资2.8%[^whjr-shr]；ETF 6万亿、代销4.69万亿（+35.3%）等财富管理侧高增[^zhongzhengxie-2025yingxiao]。
- **反例/边界**：情景推算非一致预期；若利率反转（2026Q2息差首次环比回升）则判断需修正。
- **Confidence**：中（推算）。
- **Implications**：对博士个人：金融转行的现实通道排序=量化（对理工科开放、应届总包50-80万）> 财富管理/行研 > 传统信贷条线；D01定位期直接引用。
