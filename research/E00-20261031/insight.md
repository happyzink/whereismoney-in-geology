# E00 跨维洞察（insight）

> 每条含：主张 / 跨维 / 支撑证据 / 反例与边界 / Confidence / Implications。供成稿与后续期数使用，写作时 Confidence 高的排前。

## 1. 金融（尤其银行）仍是中国利润池的心脏，但它是收缩中的最大

- **主张**：银行单独占A股净利约四成、金融约占一半，但银行占比十年下降约10个百分点、净息差连续六年收窄——"最大"不等于"扩张"。
- **跨维**：D1利润池 + D2全球榜 + D3薪酬 + D5效率。
- **支撑**：银行21749亿/约40.4%[^tmtpost-bank2025][^eastmoney-ar2025]；2014年前十公司占51%（8家银行）[^people-2014rank]；净息差1.40%、六连降[^ey-banks2025]；全球利润榜金融7家（dive_02）。
- **反例/边界**：保险券商在牛市年利润弹性极大（2025非银营收+11.02%）；"让利实体"政策可能加速缩池。
- **Confidence**：高。
- **Implications**：E01 的关键问题不是"银行赚不赚"，而是"在利润池收缩的行业里，个人还能不能分到钱"——E01 从业者维度权重上调。

## 2. 「公司的钱」与「打工人的钱」系统性分离：利润越靠资源/品牌壁垒，劳动分成越低

- **主张**：人均创利最高的公司，给员工的分成比例（人均薪酬÷人均创利）反而最低；分成高的行业利润薄。
- **跨维**：D5效率榜 + D1利润池 + D3薪酬。
- **支撑**：海油人均创利约529万/分成约8-11%（推断）、茅台235万/约13% vs 宁德39万/约61%、腾讯194万/约58%[^dive_05]；吉比特近8成利润用于分红（股东通道远宽于劳动通道）[^sina-gb-rd]。
- **反例/边界**：分成比例≠绝对薪酬（宁德比例高但绝对额23.63万）；平台生态用工口径会放大"低分成"误读；跨期薪酬口径不齐（茅台为2020年数据）。
- **Confidence**：中-高（样本内测算稳健，绝对精度有限）。
- **Implications**：选职业的定价核心是"分成结构"而非"行业利润"——P01 的核心命题；看 offer 先看激励结构。

## 3. 股东的钱已与当期利润脱钩：市值增量与造富全部由AI/半导体估值扩张主导

- **主张**：十年市值增量榜=AI算力榜；造富新贵全部来自算力链；估值扩张型（利润没跟上）与利润驱动型并存，前者占增量大头。
- **跨维**：D4市值增量 + D2全球利润榜 + D1行业增速。
- **支撑**：电子市值约8倍超银行[^xinhua-ashare]；特斯拉净利两年缩水约75%但市值1.58万亿美元（约416倍）、联讯仪器778倍 vs 茅台19.5倍[^macrotrends-tesla][^tmtpost-pe]；胡润新面孔263位、增量前十=56%[^hurun-rich2026]；英伟达FY2026净利1200.67亿美元同时兑现利润[^macrotrends-nvda-ni]。
- **反例/边界**：新华社明示"局部催生估值泡沫"；宇树上市后创始人财富从峰值1300亿回落至695亿——纸面增量≠落袋。
- **Confidence**：高。
- **Implications**：E04 上移至行业篇第3；"快钱"在估值区也在风险区；对 P02（股权期权）是机会成本坐标系。

## 4. 「什么样的钱更多」的统计答案：流量看工资，存量看股权

- **主张**：居民流量口径中工资性收入占56.6%是绝对基本盘，财产净收入仅占8.0%且增速垫底；但在存量财富口径中，高净值人群=企业主53%+金领35%——造富主通道是企业股权，不是理财。
- **跨维**：D6居民收入 + D4造富榜 + D5分成比例。
- **支撑**：五项结构[^stats-gongbao2025][^stats-income2025]；胡润：富裕家庭总财富145万亿=GDP的1.07倍，企业主53%/金领35%，亿元资产家庭中企业主80%[^hurun-wealth2025]；财产净收入+1.6%为四项最慢。
- **反例/边界**：流量与存量口径不可混算；高净值家庭数量同比-2.9%（高净值端在收缩）；财产净收入不含资产价格增值——存量收益未入统计流量。
- **Confidence**：高。
- **Implications**：对博士个人：最大可行杠杆=进入有股权激励的组织或自建企业；纯储蓄理财跑不赢——P02/P04 的立论基础。

## 5. 薪酬峰在岗位层面远陡于行业层面：选岗位 > 选行业

- **主张**：行业层面首尾差约4倍，岗位层面峰值可达全国平均的10倍以上——分布的"峰"在岗位维度。
- **跨维**：D3薪酬 + D5效率。
- **支撑**：非私营行业极差3.98倍[^stats-salary-2025]；AI科学家平均月薪137153元（约为全国平均月薪1.08万的12.7倍）[^sina-maimai-ai]；信息传输业"中层及以上管理人员"472496元[^stats-salary-2025]；芯片架构师P90约117.4万（低信度）。
- **反例/边界**：岗位分位数据样本弱（平台偏差/聚合站）；AI岗位量价随景气波动大。
- **Confidence**：中-高。
- **Implications**：D01 个人定位必须按"岗位×城市×行业"三维定价；简历策略应瞄准峰位岗位而非行业均值。

## 6. 高人均利润与大规模就业几乎不兼容：就业蓄水池在低人均创利行业

- **主张**：人均创利榜头部公司雇佣规模普遍只有数千至数万人；能大规模吸纳就业的行业人均创利垫底——个人在"窄门高分成"与"宽门低分成"之间必须二选一。
- **跨维**：D5效率 + D1利润池 + D3薪酬。
- **支撑**：拼多多约2.3万人/人均约432万 vs 宁德约18.6万人/约39万[^dive_05]；券商从业32.78万人且年减近8000人[^jj21-broker-pay]；海油2.31万人/529万。
- **反例/边界**：腾讯11.6万人/194万是"平台+高毛利"的例外；银行业（最大利润池）就业规模居前，人均创利待证。
- **Confidence**：高。
- **Implications**：D01 的根本张力：追求人均创利=接受窄门竞争；追求确定性=接受低分成。D02 行动方案必须显式取舍，不能两头都要。
